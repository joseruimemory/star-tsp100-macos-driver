This installs a native driver for the Star TSP143 receipt printer (original TSP100 series, USB). It runs on Apple Silicon and Intel Macs, without Rosetta.

What is installed:

  • the print filter and an uninstaller, in /Library/Printers/rastertostarn
  • the printer description (PPD), in /Library/Printers/PPDs/Contents/Resources

If the printer is already set up on this Mac, its print queue is switched to this driver. If it is plugged in and not set up yet, a queue named Star_TSP143 is created.

To remove the driver later, run in Terminal:

  sudo /Library/Printers/rastertostarn/uninstall.sh
